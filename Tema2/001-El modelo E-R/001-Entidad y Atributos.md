Una entidad es un objeto, persona o concepto del mundo real sobre el que queremos almacenar información. 

Atributo son las propiedades que describen una entidad. Se representan óvalos conectados a la entidad.

# Tipos de atributo 

**Simple** No se pueden dividir en partes mas pequeños con significado propio. Ejemplo: DNI.

**Compuesto** Se puede dividir en otro atributos. Ejemplo: Dirección (calle, número, código postal.

**Multivaluado**  Puede tener varios valores para la misma entidad. Se representa con un óvalo doble. Ejemplo: Teléfonos 

**Derivados** Se calcula a partir de otro atributo. Se representa con un óvalo discontinuo. Ejemplo: edad, calculada a partir de la fecha de nacimiento.

**Clave o identificador** Distingue de forma única cada entidad. En muchos diagramas se subraya. Ejemplo: DNI del alumno.
