# Modelado de BD 

## Modelado relacional 

Es un modelo lógico de como se guardan los datos en una base de datos. 

Organiza los datos en tablas (relaciones) con filas (tuplas) y columnas (atributos).

Se usa directamente en SGBD como MySQL, PostgreSQL, Oracle, etc.

Es como ves los datos cuando los consultas con SQL. 

## Modelado Entidad-Relación 

Es un modelado conceptual, pensado para diseñar/ dibujas una base de datos antes de crearla. 

Usa entidad, atributo, y relaciones entre ellas. 

Se representa gráficamente con DER (Diagramas entidad relación)

Te ayuda a entender la lógica del sistema sin pensar aun en tablas.
