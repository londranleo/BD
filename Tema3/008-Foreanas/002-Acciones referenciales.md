## 8.2. Acciones referenciales: CASCADE, SET NULL, SET DEFAULT y RESTRICT

Deginen que ocurre con los registro dependientes cuando se borra o se moidifca el registro referencial. 

Restric define la operacion 

- RESTRICT define la operacion.
- CASADE propaga el cambio. 
- SET NULL conserva los datos vincualdos pero deja el campo de conexxion vacio. 
- SET DEFAULT sustituye el dato borrando por un valor predeterminado
