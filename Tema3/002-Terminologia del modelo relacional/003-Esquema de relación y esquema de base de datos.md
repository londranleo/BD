# 2.2. Esquema de relación y esquema de base de datos

El esquema define la estructura de la base de datos: nombres de tablas, columnas,
tipos de datos, claves, restricciones y relaciones

Para relacionar la información, cada tabla utiliza una clave primaria que identifica sus
registros únicos y una clave foránea para vincularse con otras tablas.

Por ejemplo biblioteca: una tabla “Usuarios” con su clave primaria y
una tabla “Préstamos” con una clave foránea que indique qué usuario ha realizado cada
préstamo.

Las vistas y los permisos (DCL) forman parte de la administración. El esquema es la estructura lógica sobre la que se apoyan.
