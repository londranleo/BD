# 3.3 Tipos de SGBD 

Actualmente te se guardan los datos en sistemas informáticos especializados para administrar esta información se utiliza un programa llamado SGBD esta herramienta permite almacenar y buscar datos de forma segura ademas ayuda a cumplir obligación es legales. 

Existen varios tipos de SGBD: 

| Tipo                    | Característica                                                                                                           | Ejemplos (SGBD)                                         | Uso                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- | ------------------------------------------------------- |
| **Relacional**          | Guardan la información en tablas conectadas entre si  suelen utilizar SQL.                                               | MySQL, MariaDB, PostgreSQL, Oracle Database, SQL Server | Gestión, tiendas online, facturación, registro bancario |
| **NoSQL**               | Destacan por ser muy flexibles dentro de NoSQL se encuentran modelos documentales, clave-valor, columnas anchas, grafos. | MongoDB, Redis, Cassandra, Neo4j                        | Redes sociales                                          |
| **NewSQL**              | Combinan el uso de tablas con una alta velocidad de trabajo y capacidad de distribución.                                 | CockroachDB, TiDB, Google Spanner                       | Sistemas globales de alta concurrencia                  |
| **Orientado a objetos** | Almacenan la información en bloques de datos mas complejos integrando datos (cercano a POO)                              | —                                                       | Ingeniería                                              |

La elección de tipo depende de tipo de información, volumen, necesidad de relaciones, numero de usaros simultáneos, los requisitos de seguridad y del rendimiento.
