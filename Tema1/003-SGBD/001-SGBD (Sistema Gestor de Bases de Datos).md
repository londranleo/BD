SGBD es un programa que permite crear mantener y controlar una BD.

Cada proyecto necesita organizar sus datos de forna distinta, por este motivo existen diferentes clases los NoSQL, NewSQL y los orientados a objetos

# 3.1 Funciones den SGBD

Us SGBD cumple varias funciones técnicas:

| Función        | Descripción                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------ |
| Almacenamiento | Guarda los datos de forma organizada y persistente                                               |
| Recuperación   | Permite restaurar la información si ocurre un fallo o se<br>necesita volver a una copia anterior |
| Concurrencia   | Gestiona accesos simultáneos reduciendo conflictos e<br>inconsistencias.                         |
| Integridad     | Datos correctos y coherentes con las reglas; evita valores imposibles o que rompan relaciones    |
| Seguridad      | Protege los datos de accesos no autorizados                                                      |

Un SGBD pueden realizar copias de seguriadad, restaurar datos, registrar operaciones realizadas por usuarios y ejecutar transacciones para que varias operaciones se completen o se cancelen.
