# 4.1 DB Centralizada 

Una BD centralizada guarda toda la información en un único servidor. La mayor ventaja de este modelo es su instalación rápida. Todo el control se concentra en un solo lugar. 

Concentra el riego, si falla todo se detiene, si no se han configurado copias de seguridad, servidores de respaldo o soluciones de alta disponibilidad.

Encajan en app pequeñas o medianas, administración interna, prototipos. pocos usuarios concurrentes.

Para reducir riesgos  deben configurarse copias de seguridad, monitorización, restauraciones probada y servidor de respaldo.
