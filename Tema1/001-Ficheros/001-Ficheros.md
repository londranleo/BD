Guarda informacion de forma adecuada permite que que una applicaion wev recipere dartos.

Existen 3 tipos de archivos habituales 

| Tipo               | Cómo guarda / busca                                                                                                                     | Uso ideal            | Velocidad                |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ------------------------ |
| **Plano**          | Guarda la informacion de forma Secuencial (Colando cada dato nuevo al final). Para encontar un refistro hay que leer desde el principio | Pocos datos          | Lenta                    |
| **Indexado**       | Fichero + **índice** (estructura auxiliar que relaciona claves con la posición del registro)                                            | Búsquedas frecuentes | Rápida                   |
| **Acceso directo** | **Calcula la posición** del registro a partir de una clave (operación matemática sobre un identificador único)                          | Acceso inmediato     | Alta en accesos directos |
