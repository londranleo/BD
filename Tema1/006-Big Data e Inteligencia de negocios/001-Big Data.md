# 6.1 Concepto de Big Data (Las 5V)

Para procesar grandes volúmenes de información, se utilizan redes que reparten el trabajo entre varios equipos. Este manejo de grandes cantidades de datos se llama Big Data. 

El Big Data suele describirse mediante cinco dimensiones conocidas como las 5V.

| V | Significado |
|---|---|
| **Volumen** | Cantidad de información almacenada |
| **Velocidad** | Rapidez con que se generan y procesan |
| **Variedad** | Diversidad de formatos (texto, imágenes, audio, vídeo) |
| **Veracidad** | Fiabilidad de los datos (si son incompletos, duplicados o incorrectos, las conclusiones también) |
| **Valor** | Utilidad práctica para decidir (no todos los datos aportan valor) |

>Cruzar muchos datos puede revelar información personal aunque cada dato por separado parezca inofensivo. Por eso aquí la privacidad es todavía más importante.
