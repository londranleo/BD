# 5.1 RGPD (Europa)

El reglamento de UE 2026/679, RGPD permite tratar datos personales cuando existe una base jurídica validad. 

Como el consentimos, la ejecución de un contrato, una obligación legal o interés legitimo correctamente justificado .

Cuando el motivo es el consentimiento, tiene que ser libre,  informado, especificado e inequívoco. Y nunca se guardan datos sim avisar antes a la persona.

Derechos de las personas: 
- Acceso: ver que datos suyos tienes.
- Rectificación: corregirlos si están mal. 
- Supresión ("derecho al olvido"): que se borren cuando ya no haya motivo para guárdalos
- **Limitación:** restringir el uso que se hace de ellos.
- **Oposición:** negarse a ciertos usos.
- **Portabilidad:** recibir sus datos en un formato ordenado para llevárselos a otro sitio.
