# 2.3 Tipos según la ubicación

Una BD puede clasificase según donde se almacenan y desde donde se accede a ella, esta ubicación afecta el rendimiento, administración, disponibilidad y las medidas de seguridad. 

| Tipo | Almacenamiento |
|---|---|
| **Local** | Equipo propio |
| **Remota** | Servidor externo accesible por red |
| **Nube** | Servidores de un proveedor externo, por internet |
| **Híbrida** | Equipo propio + online |

La obligación legal de proteger datos existe **Donde sea**  que estén. Valorar quién administra la infraestructura, dónde se alojan los datos, qué permisos se aplican y qué garantías ofrece.

Las grandes empresas usan BD distribuidas por todo el mundo: si un equipo falla, la web sigue funcionando.
