# Dónde están las BD

Las bases de datos se encuentran en el nivel mas bajo dentro de un entorno de un sistemas de base de datos.

Generalmente se los considera como parte ¨Física", ya que, aunque sean un contenido lógico, se encuentran almacenados o creadas en un dispositivo físico. Por ejemplo: Un servidos.

Para que un usuario pueda acceder a los datos en base de datos, necesita de un software especial conocido como SGBD (Sistema gestor de base de datos) o DBMS (Data base managment system).
