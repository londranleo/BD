# Que es un servidor de DB

Un servidor es una computadora que ofrece servicios o recursos a otras computadoras, llamadas clientes, a través de una red.

Un servidor de base de datos es justamente una computadora(local o remota) que se encarga de almacenar, organizar y permitir el acceso a datos de forma segura y eficiente. 

El servidor de bases de datos es quien tiene instalado dentro al SGBD. 

Por ejemplo puede tener un servidor con MySQL, otro con Oracle, otro con una base de datos no relacional, etc. 

Para poder usar base de datos tenemos que contar o instalar un servidor.
